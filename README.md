# Hail Lions Website & Scheduler

Mobile paintless dent repair for greater Houston — marketing site + photo-first booking flow.

**Phone:** (281) 352-5434  
**Stack:** Next.js 15 · Tailwind CSS · TypeScript  

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

1. Import this repo in Vercel
2. Framework: Next.js (auto-detected)
3. Deploy

Then point haillions.com to the Vercel project when ready.

## Main routes

| Path | Description |
|------|-------------|
| `/` | Homepage |
| `/book` | 5-step photo booking |
| `/services/*` | Service detail pages |
| `/areas/*` | Local SEO city pages |
| `/about` | About Jason / Hail Lions |
| `/guarantee` | Satisfaction + lifetime warranty |
| `/contact` | Call and book |

Built exclusively for Hail Lions LLC.
